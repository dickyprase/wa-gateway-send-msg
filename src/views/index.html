Authentication

Ada 2 jenis auth yang dipakai:

  • JWT Token — untuk endpoint dashboard (/api/gateway/*). Kirim di header: Authorization: Bearer <token>
  • API Key — untuk endpoint kirim pesan (/api/send). Kirim di header: x-api-key: <key>

POST /api/send — Kirim Pesan

Endpoint utama untuk mengirim pesan WhatsApp. Support 2 mode:

Mode 1: Kirim ke 1 nomor 
{
  "to": "6281234567890",
  "message": "Teks pesan..."
}
Mode 2: Broadcast ke banyak nomor 
{
  "recipients": ["6281234567890", "6289876543210", "08211111111"],
  "message": "Teks pesan..."
}
Response sukses 
{
  "success": true,
  "sent": 2,
  "failed": 0,
  "results": [
    { "success": true, "phone": "6281234567890@s.whatsapp.net" },
    { "success": true, "phone": "6289876543210@s.whatsapp.net" }
  ]
}

Contoh: cURL

# Kirim ke 1 nomor
curl -X POST http://localhost:3001/api/send \
  -H "Content-Type: application/json" \
  -H "x-api-key: wag_api_key_rahasia_2024" \
  -d '{"to":"6281234567890","message":"Halo dari gateway"}'

# Broadcast ke banyak nomor
curl -X POST http://localhost:3001/api/send \
  -H "Content-Type: application/json" \
  -H "x-api-key: wag_api_key_rahasia_2024" \
  -d '{
    "recipients": ["6281234567890", "6285678901234"],
    "message": "Tiket baru masuk"
  }'

Contoh: PHP

<?php
function notif_to_wa($recipients, $message) {
    if (empty($recipients) || empty($message)) return false;

    $payload = ['message' => $message];
    if (is_array($recipients)) {
        $payload['recipients'] = array_values(array_filter($recipients));
    } else {
        $payload['to'] = $recipients;
    }

    $ch = curl_init('http://localhost:3001/api/send');
    curl_setopt_array($ch, [
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => json_encode($payload),
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT        => 5,
        CURLOPT_CONNECTTIMEOUT => 3,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'x-api-key: wag_api_key_rahasia_2024',
        ],
    ]);

    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    if (!$response || $httpCode !== 200) return false;
    $data = json_decode($response, true);
    return !empty($data['success']);
}

// Contoh pemakaian:
$staffPhones = ['6281234567890', '6285678901234'];
$pesan = "Tiket Baru Masuk\nKode: TKT-001\nDari: Budi";
notif_to_wa($staffPhones, $pesan);
?>

Environment Variables

Konfigurasi ada di file .env:

PORTPort server (default: 3001)
JWT_SECRETSecret key untuk JWT (min 32 karakter)
JWT_EXPIRES_INMasa berlaku token (contoh: 24h)
DASHBOARD_USERNAMEUsername login dashboard
DASHBOARD_PASSWORDPassword login dashboard
WA_API_KEYAPI Key untuk endpoint /api/send

Tips

  • Nomor bisa format 08xx, 628xx, atau 8xx — auto normalisasi ke format internasional
  • Pesan mendukung format WhatsApp: *bold*, _italic_, ~strikethrough~
  • Timeout request disarankan 5 detik agar aplikasi tetap responsif walau gateway mati
  • Auto-reconnect: jika koneksi WA terputus (bukan logout), gateway akan reconnect otomatis
  • Session tersimpan di folder auth_info/ — jangan di-commit ke git
